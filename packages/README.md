## Panduan Instalasi di Perangkat Android (Poco F3 / Xiaomi / HyperOS / MIUI)

1. **Unduh Berkas APK**:
   - Unduh langsung [`MusicEuy-v1.0.0.apk`](./MusicEuy-v1.0.0.apk) dari repositori ini atau melalui menu [GitHub Releases](https://github.com/rafliadipratama/MusicEuy-Android/releases).
2. **Izin Sumber Tidak Dikenal (*Install Unknown Apps*)**:
   - Jika muncul peringatan saat membuka APK di Chrome atau File Manager, masuk ke:
     `Setelan (Settings) -> Privasi & Keamanan -> Pasang Aplikasi yang Tidak Dikenal (Install Unknown Apps)`.
   - Berikan izin (*Allow*) untuk File Manager atau Browser Anda.
3. **Pasang & Buka**:
   - Ketuk **Instal**.
   - Buka aplikasi **MusicEuy**. Aplikasi langsung siap memutar lagu tanpa login akun apa pun!

## Fitur Utama

- **Penyedia Streaming Cerdas**: Integrasi NewPipeExtractor v0.26.5 untuk YouTube Music audio resmi berkecepatan tinggi (Opus 160-320kbps).
- **Metadata Spotify Publik**: Akses langsung tangga lagu *Top 50 Indonesia* harian & playlist publik Spotify tanpa login.
- **Lirik Real-time**: Lirik tersinkronisasi otomatis dari LRCLIB.
- **Arsitektur Ekstensi Modular**: Dukungan plugin eksternal ala Spotube/Audion di tab Ekstensi.
- **Desain Modern Obsidian & Electric Green**: Dilengkapi Bottom Navigation Bar dan docked MiniPlayer interaktif.
